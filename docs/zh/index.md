1. 阅读[示例](./examples/index.md)，完成从安装到运行 Logger 的全流程。

3. 需要高频签名和边界时，查询[中文高频 API](./api/index.md)；较少使用的符号仍进入[英文完整 API 参考](../api/index.md)。
