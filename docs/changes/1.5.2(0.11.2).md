## BitLogger Update Changes

version 1.5.2(0.11.2)

### Changes

- Pin development and CI to MoonBit compiler `0.10.20+65efd5b93` and CLI `0.1.20261104`, and replace the remaining legacy derive syntax.
- Update async to 0.22.9, OpenTelemetry to 0.1.8, and moonyaml to 0.1.7; constrain the transitive protobuf runtime to 0.2.0.

### Verification

- Verification used `moonc v0.10.20+65efd5b93 (2026-11-05)` and `moon 0.1.20261104` on Linux x86_64.
- Strict check and test passed on native, JavaScript, and wasm: complete suites 320/312/312 and `src-async` suites 115/108/108. Eight native examples and the native release build passed.
- Wasm-gc strictly checks and runs the complete synchronous suite (204 tests); the separately selected `src` suite has 202 tests.
- Correct the async support declaration to native, js, and wasm. Upstream async 0.22.9 explicitly does not support wasm-gc, and a minimal 0.22.4 baseline executed zero wasm-gc async tests. Earlier CI did not establish async runtime support there. All 115/108/108 existing async tests remain enabled on supported targets.
- `moon fmt --check`, `moon info`, a recursive registry-version audit, and the VitePress documentation build passed. Package contents exclude local databases, generated logs, Node dependencies, and built documentation.

### Notes

- The synchronous API and native/js/wasm async API remain unchanged. Wasm-gc is supported for synchronous logging only. Dependency versions match the latest non-yanked registry releases checked on 2026-11-13.
