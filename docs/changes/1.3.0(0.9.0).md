## BitLogger Update Changes

version 1.3.0(0.9.0)

### Changes

- Normalize W3C trace ids, span ids, flags, and trace state through `moonbit-community/opentelemetry@0.1.7`. Identifiers that are not valid hex stay unchanged.
- Parse logger config text that does not start with `{` or `[` as YAML 1.2 through `moonbitstack/moonyaml@0.1.1`. JSON text keeps the existing parser and the `Invalid JSON:` error prefix.
- Redact matched fields with `sujy123456/lunasieve@0.1.0`. A value with no detected secret becomes the placeholder; a detected secret span is replaced in place.

### Verification

- `moon test --target native`: 311 passed, 0 failed.

### Notes

- Public parser, trace, and redaction signatures are unchanged.
- BitLogger still does not export OTLP or parse `traceparent` headers.
