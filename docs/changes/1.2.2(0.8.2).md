## BitLogger Update Changes

version 1.2.2(0.8.2)

### Changes

- Upgrade `moonbitlang/async` to `0.22.4` and keep native file operations returning `Bool` or `0` instead of aborting when the current MoonBit fs API raises.
- Declare sink `write` and `write_async` methods explicitly so they stay available under the current implicit-impl warning.
- Drop unused package imports reported by the current compiler and keep the existing black-box test style compatible with `deny-warn`.

### Verification

- moon fmt
- moon check --deny-warn on the default, native, wasm, wasm-gc, and js targets
- moon test --deny-warn on native, wasm, wasm-gc, and js
- moon test src-async --deny-warn on native, wasm, wasm-gc, and js
- moon run examples/basic

### Notes

- Sink `write` and `write_async` are now explicit methods in the generated interface. Behavior is unchanged.
- Missing files and failed native file operations still surface as unavailable sinks or false results; they no longer abort the process.
