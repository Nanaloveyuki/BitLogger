## BitLogger Update Changes

version 1.6.0(0.12.0)

### Changes

- Build with MoonBit 1.0 RC1 and use the standard library async runtime for logging and file sinks.
- Update moonyaml to 0.2.1. The asynchronous queue type now comes from `moonbitlang/core/async`.

### Verification

- The Linux native, JS, Wasm and Wasm GC suites passed. The Windows native suite also passed.
